# Xilancer - HTML/CSS Project

Hello! This is my practice project where I converted a Figma design for a freelance website called **Xilancer** into a real webpage using HTML and CSS.

## What I Built

Here are the main parts of the website I made:

- A top header with a search bar.
- Grids to show "Popular Categories" and "Popular Services".
- Cards that display the latest jobs and top-rated freelancers.
- A section for pricing plans with Free, Business, and Enterprise options.
- A review section with user quotes and a banner to download the mobile app.
- A simple footer at the bottom with links.

## Built With

- **HTML**: Used for the basic structure of the page.
- **CSS**: Used to add colors, grids, and style everything.
